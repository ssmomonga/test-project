# IT研究会のGoogle Workspace導入について

下記の通り、IT研究会でGoogle Workspace(以降、GWSと記載)を導入する。 

## 1. 目的
GWSの高機能サービスの利用や、IT研究会の持つIT資産の移行を目的とする。
1. ビデオ会議ツールの確保
   - これまでIT研究会の定例会で利用しているビデオ会議ツールは、中川元代表のZoom個人アカウントを利用していた
   - 体制変更に伴い、個人に依存しないビデオ会議ツール（GoogleMeet）を確保したい
2. AppSheetのサブスクリプション機能の活用
   - ノーコードチームではAppSheet活用に注力しているが、個人アカウントでは機能制限がある
   - デプロイなどの高機能を活用したい
3. IT資産の一元化
   - MLやホームページなどを一元管理したい
   - 実施方針は今後検討

### 契約期間内のアカウント追加、削除について
GWSの年間契約では以下の縛りがある
- 契約期間：　1年間
- 契約期間途中でのアカウント契約数の増加：　可能。契約終了日までの日割り計算で追加料金を支払う
- 契約期間途中でのアカウント契約数の減少：　不可能。アカウントの削除により空きが生じても返金されない
- アカウントの再利用：　可能。アカウントの削除により空きが生じた場合、それを再利用しても追加料金は不要　→　このアカウントの集金が剰余金となります
